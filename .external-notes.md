# External integration notes

- Meta WhatsApp webhook overview: https://developers.facebook.com/documentation/business-messaging/whatsapp/webhooks/overview
  - WhatsApp Business Platform sends JSON webhooks for messages and statuses.
  - Messages webhooks require `whatsapp_business_messaging` permission.
- Meta webhook endpoint setup: https://developers.facebook.com/documentation/business-messaging/whatsapp/webhooks/create-webhook-endpoint/
  - GET verification uses `hub.mode=subscribe`, `hub.verify_token`, and `hub.challenge`.
  - POST payloads must validate `X-Hub-Signature-256` with HMAC-SHA256 using the app secret.
  - Meta retries failed/unacknowledged deliveries, so deduplication is required.
- Meta service messages: https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/send-messages
  - Free-form text service messages use `POST /<WHATSAPP_BUSINESS_PHONE_NUMBER_ID>/messages` with `messaging_product`, `recipient_type`, `to`, `type: text`, and a `text.body` object.
  - Authorization is a Bearer token.
  - Free-form service messages are only allowed during the 24-hour customer service window; outside it, templates are required.
  - A successful API response means the request was accepted; delivery status arrives via webhooks.
- WebDev owner notifications: `/home/ubuntu/skills/webdev-owner-notifications/SKILL.md`
  - Use the server-side `notifyOwner({ title, content })` helper for escalation and operational alerts.
